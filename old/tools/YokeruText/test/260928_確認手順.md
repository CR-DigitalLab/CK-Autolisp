# YokeruText 動作確認手順

テスト図面：`YokeruText_test.dxf`（24区画。各区画の見出しの下に「期待：〜」として正常な結果を書いてあります）

AutoCAD で試す前に、簡易シミュレータ lispcheck でできる範囲の確認は済ませてあります（[lispcheck結果/検証結果.md](lispcheck結果/検証結果.md)）。特に AutoCAD で見てほしいのは、寸法の文字（区画21・22）・マルチ引出線（区画23・24）・マルチテキスト（区画04・12）・矢印と赤枠の表示・UCS（区画19）・AutoCAD の Undo です。

見出しと区画の枠は**ロック画層**（`YK_見出し`・`YK_区画`）に置いてあるので、全体を選んでも動きません（結果の「ロック画層」の件数に入ります）。

## 準備

1. `YokeruText_test.dxf` を開き、DWG として別名保存（テストで変わるため、元の DXF は残しておく）。
2. `APPLOAD` で `YokeruText.lsp` を読み込む。
3. 設定を初期値にしておく：`YKS` → `R`（初期値）→ Enter。

## 確認の流れ

基本は「区画を窓選択 → `YK`」または「`YK` → 区画を窓選択 → Enter」。結果を見たら `U`（元に戻す）で戻して次へ進むと、図面を汚さずに続けられます。

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01 線と重なった文字 | 区画を選んで `YK` | 3つとも線から離れるか。移動が小さい文字に引出線が付いていないか |
| 02 文字どうしの重なり | 同上 | 3つが重ならなくなるか。全部が大きく飛ばないか |
| 03 回転した文字 | 同上 | 回転角が変わらず、線から離れるか |
| 04 マルチテキスト | 同上 | 3行全体が円・線から離れるか（1行目だけ離れて2行目が重なる、はNG） |
| 05 位置合わせ | 同上 | 右寄せ・中央・中央中心の文字が、正しく線から離れるか（逆に重なりが増える、はNG） |
| 06 寸法の近く | 同上 | 寸法線・寸法値・補助線と重ならないか |
| 07 図枠ブロックの中 | 同上 | 文字が図枠の外へ飛び出さないか（図枠全体を障害物扱いしていないか） |
| 08 記号ブロック | 同上 | 記号の上から文字がどくか |
| 09 ロック画層 | 同上 | 文字が動かず、結果に「ロック画層 1」と出るか |
| 10 固定画層 | ① そのまま `YK` → 動く ② `YKS` → `F` → `FIX` と入力 → もう一度 `YK` → 動かない | 設定が効くか。**確認後 `YKS` → `F` → `.` で空に戻す** |
| 11 非表示・フリーズ画層の線 | 区画を選んで `YK` | 文字が動かないか（重なり 0） |
| 12 逃げ場なし | 同上 | 赤枠で表示され、終了後に選択状態になるか。`YKS` → `K`（マスクON）で再実行すると、MTEXT に背景マスクが付くか（確認後マスクOFFに戻す） |
| 13 密集した注記 | 同上 | 10個が重ならずに散らばるか。大きく動いたものに引出線が付くか |
| 14 曲線 | 同上 | 円弧・スプラインの形に沿って判定しているか（曲線から少し離れた空白には置いてよい） |
| 15 ハッチの上 | ① そのまま `YK` → 動かない ② `YKS` → `H`（ハッチON）→ `YK` → ハッチの外へ出て引出線が付く | 設定が効くか（確認後ハッチOFFに戻す） |
| 16 重なっていない文字 | 区画を選んで `YK` | 何も動かないか（「重なり 0 個」） |
| 17 長い文字 | 同上 | 文字全体が線から離れるか |
| 18 3Dに傾いた文字 | 同上 | 動かず、「非表示/3D/その他」に数えられるか |
| 19 UCS・ズーム | ① `UCS` → `Z` → `30` で回転してから `YK` ② UCS を戻し、この区画だけ大きく拡大して `YK` | どちらも 01 と同じような結果になるか |
| 20 少しだけ重なった文字 | 区画を選んで `YK` | わずかに動くだけで、引出線が付かないか |
| 21 寸法の文字に線 | ① そのまま `YK` → 動かない ② `YKS` → `T`（寸法の文字ON）→ `YK` | ②で寸法の文字が寸法線に沿って横へずれるか。寸法の値・矢印・補助線が変わらないか。寸法線の動き方は寸法スタイルの「文字の移動」の設定によります |
| 22 寸法の文字どうし | T ON のまま区画を選んで `YK` | 片方の文字が横へずれて重ならなくなるか。確定前に `U`（元に戻す）→ 文字が元の標準の位置に戻るか |
| 23 マルチ引出線の文字に線 | ① `YKS` → `T` で寸法の文字OFF に戻す ② そのまま `YK` → 動かない ③ `YKS` → `U`（マルチ引出線ON）→ `YK` | ③で文字と折れ線が線から離れ、**矢印の先は丸印の中心のまま**か |
| 24 引出線2本のマルチ引出線 | U ON のまま区画を選んで `YK` | 文字が線から離れ、2本とも矢印の先が丸印の中心のままか。確認後 `YKS` → `U` で OFF に戻す |

## まとめて確認

- 図面全体：何も選ばずに `YK` → Enter → `A`（図面全体）。
- Esc の確認：「確定しますか？」の表示中に Esc → 全部元に戻り、「中止しました。変更は元に戻しました。」と出るか。
- Undo の確認：確定したあとに `U`（AutoCAD の Undo）を1回 → 実行前の状態に戻るか（引出線も消えるか）。
- 設定画面：`YKS` で各項目を変更 → AutoCAD を再起動しても設定が残っているか。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージ（あれば画面の写真）を教えてください。

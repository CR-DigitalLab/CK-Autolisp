# YokeruText（ヨケルテキスト）

重なっている文字を、空いている場所へ自動で逃がす AutoLISP です。対応：AutoCAD 2027。

| コマンド | ショートカット | 内容 |
|---|---|---|
| `YOKERU` | `YK` | 文字の重なりを自動で避ける |
| `YOKERUSET` | `YKS` | 設定画面 |

## 使い方

1. `APPLOAD` で `YokeruText.lsp` を読み込む（UTF-8 で保存してあります）。
2. `YK` → 逃がしたい文字を選んで Enter。
   - 先に文字を選んでから `YK` でも可。
   - 何も選ばずに Enter →「図面全体(A)／設定(S)／終了(X)」を選べます。
3. 動いた文字は**緑の矢印**、逃げ場がなかった文字は**赤枠**で表示されます。
4. Enter で確定、`U` で全部元に戻す（Esc でも全部元に戻ります）。
5. 逃げ場がなかった文字は、終了後に選択状態になります（手直し用）。

## 仕組み（かんたんに）

- 図面の座標だけで判定するので、画面のズーム状態に左右されません。
- 周りの図形をマス目に振り分け、近くのものだけを比べるので、文字が多くても速く動きます。
- 文字は「回転した四角」、線・円弧・ポリラインは「細かい線分」として正確に判定します。寸法は中の線・矢印・寸法値ごとに判定します。
- 元の位置のまわりを輪状に探し、「移動距離が短い」「文字の上下方向へ動く」場所を優先します。
- 込み合っている所から順に処理し、逃げ場がなかった文字は周りが動いた後にもう一度探します（最大3周）。
- 大きく動いた文字には、元の位置から引出線（線分）を自動で引きます。

## 設定（YKS）

| 項目 | 初期値 | 内容 |
|---|---|---|
| 余白(C) | 0.25 | 文字どうし・図形との間に空ける余白（文字高さに対する割合） |
| 距離(D) | 6 | 最大でどこまで動かすか（文字高さの何倍） |
| 方向数(N) | 16 | 何方向を探すか（4〜64） |
| 引出線(L) | する | 大きく動いた文字に引出線を付ける |
| 引出線距離(E) | 1.5 | この距離（文字高さの何倍）以上動いたら引出線 |
| ブロック(B) | する | ブロックを障害物にする（小さいものは中身あり、大きいもの＝図枠などは外形線だけ） |
| 寸法(M) | する | 寸法を障害物にする |
| ハッチ(H) | しない | ハッチを障害物にする（外形の四角の内側すべて。ハッチの上の文字は外へ逃がす） |
| 固定画層(F) | なし | この画層の文字は動かさない（障害物としては扱う） |
| 無視画層(I) | なし | この画層の図形は障害物にしない |
| マスク(K) | しない | 逃げ場がなかったマルチテキストに背景マスクを付ける |
| 確認(O) | する | 実行後に確定／元に戻すを確認する |
| 初期値(R) | ― | すべて初期値に戻す |

設定はユーザーごとに記憶され、次回も引き継がれます。

## 対象と注意

- 動かすのは、現在の空間（モデル／レイアウト）の**文字（TEXT）とマルチテキスト（MTEXT）**です。
- 次の文字は動かしません（件数を表示します）：ロックされた画層、非表示・フリーズの画層、固定画層、3D に傾いた文字。
- 属性・マルチ引出線・寸法の文字は動かしません（障害物として扱います）。
- 引出線は、すべての文字を配置した後に引くため、まれに他の文字と交差することがあります。
- Undo 1 回で、実行前の状態に戻ります。

## 作成ルールへの対応

- Undo グループ（エラー・Esc のときも正しく閉じる）
- 完了時に結果（対象・重なり・移動・引出線・逃げ場なし・処理時間）を表示
- ショートカット（YK / YKS）
- システム変数は変更しない（UCS・UCSFOLLOW・OSMODE に依存しない。計算はすべて図面座標）
- Esc・選択なしでも安全に終了（処理途中の Esc は全部元に戻す）
- コマンドを使わない作りのため、`*error*` 内の command-s も不要

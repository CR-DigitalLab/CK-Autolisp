# KirokuTsuzuki（キロク・ツヅキ）

開いている図面を記録しておき、あとでまとめて開き直す AutoLISP です。対応：AutoCAD 2027。

> 記録と再開を1つのダイアログにまとめた後継版 [ProjectSet](../ProjectSet/README.md)（`PJ`）があります。

| コマンド | ショートカット | 内容 |
|---|---|---|
| `KIROKU` | `KR` | 開いている図面を記録する（ダイアログ） |
| `TSUZUKI` | `TZ` | 記録した図面をまとめて開く（ダイアログ） |
| `KIROKUSET` | `KRS` | 記録の保存先を変える（ダイアログ） |

コマンドラインだけで操作したいとき（スクリプトなど）は、`-KIROKU`・`-TSUZUKI`・`-KIROKUSET` を使います。ダイアログを表示できない環境では、自動でコマンドライン版に切り替わります。

## 使い方

1. `APPLOAD` で `KirokuTsuzuki.lsp` を読み込む（ANSI＝Shift-JIS で保存してあります）。
2. **作業を終えるとき：`KR` → Enter**
   - 開いている図面の一覧が出ます。記録の名前は最初から「前回」になっているので、そのまま Enter（［記録する］）で記録。
   - 名前を変えれば、名前を付けて記録できます（例：現場A）。同じ名前があるときは、もう一度［記録する］を押すと上書きします。
3. **作業を再開するとき：`TZ` → Enter**
   - 左に記録の一覧（最後に使った記録が選ばれた状態）、右にその記録の図面が出ます。そのまま Enter（［開く］）で開きます。
   - 別の記録を開くときは、左で選んで［開く］（またはダブルクリック）。
   - いらない記録は［この記録を削除］（2回押すと削除）。

## ダイアログ

**KR（記録）**
```
┌ 図面を記録（KIROKU） ─────────────────────────┐
│ 開いている図面を記録します（記録される図面 3 枚）          │
│ ┌──────────────────────────────┐ │
│ │ 平面図.dwg                                          │ │
│ │ 立面図.dwg          ※保存していない変更あり          │ │
│ │ Drawing1.dwg        ※一度も保存していないため記録されません│
│ │ 配置図.dwg                                          │ │
│ └──────────────────────────────┘ │
│ 記録の名前： [前回                     ]                │
│ 同じ名前の記録があると上書きされます（「前回」はいつも上書き）│
│                              [ 記録する ] [キャンセル]   │
└────────────────────────────────┘
```

**TZ（まとめて開く）**
```
┌ 図面をまとめて開く（TSUZUKI） ──────────────────────────┐
│ 記録                          │ 「前回」の図面 3 枚（開く 2 枚・開いている 1 枚）│
│ ┌───────────────┐ │ ┌──────────────────────┐ │
│ │前回    2026/09/28 18:05 3枚│ │ │平面図.dwg                                  │ │
│ │現場A   2026/09/27 17:40 5枚│ │ │立面図.dwg                                  │ │
│ └───────────────┘ │ │配置図.dwg          ※すでに開いています     │ │
│ [この記録を削除]              │ └──────────────────────┘ │
│                               │ 保存先：C:\…\KirokuTsuzuki\（初期値）        │
│ [保存先を変更...]                                    [ 開く ] [キャンセル] │
└──────────────────────────────────────────┘
```
※実際の見た目は AutoCAD の画面に合わせて少し変わります。

## 動き

- **記録するのは図面の場所だけ**です。図面そのものは保存しません。
  - 保存していない変更がある図面は、記録したうえでコマンドラインにも名前を表示します。
  - 一度も保存していない図面（Drawing1 など）は場所が無いため記録できません。
- 記録しても図面は閉じません。
- `TZ` では：
  - すでに開いている図面は二重に開きません。
  - 見つからない図面（移動・削除）は飛ばして、最後にまとめて表示します。
  - ほかの人が使用中の図面は読み取り専用で開いて、その旨を表示します。
  - 最後に、記録したときに前面だった図面を前面にします。
- 保存先の初期値は AutoCAD のユーザー設定フォルダの中（`…\KirokuTsuzuki\`）です。共有フォルダにすると別の PC でも使えます（`TZ` の［保存先を変更...］または `KRS`）。

記録ファイルは `名前.krk`（UTF-8 のテキスト）です。保存先と最後に使った記録の名前は、ユーザーごとに記憶されます。

## 作成ルールへの対応

- Undo グループ（図面は変更しないため、Undo しても変化なし）
- 完了時に結果（記録・開いた枚数、未保存・見つからない・読み取り専用の図面）をコマンドラインに表示
- ショートカット（KR / TZ / KRS）
- システム変数は変更しない
- Esc・キャンセルでも安全に終了
- ダイアログの定義（DCL）は実行時に一時フォルダへ ANSI で書き出して使い、終了時に削除（LSP 1本で動く）

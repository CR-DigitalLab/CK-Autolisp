# KirokuTsuzuki 動作確認手順（1.1.0 ダイアログ版）

テスト用の図面セット：`図面セット/` の 5 つの DXF（各図面に、役割と「こうなれば正常」を書いてあります）

| 図面 | 役割 |
|---|---|
| 01_平面図 | いつもどおり開く図面（KR のとき前面にしておく） |
| 02_立面図 | 変更して保存しない図面 |
| 03_配置図 | TZ の前に開いておく図面 |
| 04_詳細図 | KR のあと名前を変える図面 |
| 05_断面図 | ほかの人が使用中の図面 |

AutoCAD で試す前に、lispcheck でできる範囲の確認は済ませてあります（[lispcheck結果/検証結果.md](lispcheck結果/検証結果.md)）。

## 準備

1. `図面セット` フォルダを、試しやすい場所（例：デスクトップ）にフォルダごとコピーする（元のファイルは残しておく）。
2. `APPLOAD` で `KirokuTsuzuki.lsp` を読み込む。
3. `KR`・`TZ`・`KRS` を打って、ほかのコマンドと重なっていないか確認（何か別のものが動いたら教えてください）。

## まず見てほしいこと（ダイアログの表示）

- ダイアログの**日本語が文字化けしていないか**（いちばん大事。化けていたら写真を送ってください）
- 文字が切れていないか、ボタンや一覧の大きさ・並びが見やすいか

## 確認の流れ

| # | 手順 | 見るところ |
|---|---|---|
| 1 | コピーした 01〜04 を開く。02_立面図 の円を少し動かす（保存しない）。新規図面（Drawing1）も1つ作る。最後に 01_平面図 を前面にする | ― |
| 2 | `KR` | 一覧に4枚が出て、02 に「※保存していない変更あり」、Drawing1 に「※一度も保存していないため記録されません」と出るか。名前が「前回」になっているか |
| 3 | そのまま Enter | ダイアログが閉じ、コマンドラインに「「前回」に図面 3 枚を記録しました」＋注意2行が出るか |
| 4 | `KR` → 名前を `現場A` にして［記録する］ | 「現場A」に記録されるか |
| 5 | `KR` → 名前を `a/b` にして［記録する］ | ダイアログの中に「使えない文字」の注意が出て、閉じないか（キャンセルで閉じる） |
| 6 | `KR` → 名前を `現場A` にして［記録する］ | 「既にあります。もう一度…」と出るか。もう一度押すと上書きされるか |
| 7 | すべての図面を閉じる（02 は保存しない）。03_配置図 だけを開く | ― |
| 8 | `TZ` | 左に「現場A」「前回」が並び、最後に使った「現場A」が選ばれているか。右に図面と「※すでに開いています」（配置図）が出るか |
| 9 | 左で「前回」を選ぶ → Enter | 右の一覧が切り替わるか。Enter で 01・02 が開き、最後に 01_平面図 が前面になるか |
| 10 | 全部閉じる。エクスプローラーで 04_詳細図 の名前を変える（例：04_詳細図_old）。どれか1枚だけ開いて `TZ` | 右の一覧で 04 に「※見つかりません」と出るか。［開く］でほかは開き、コマンドラインに「見つからない図面」と出るか |
| 11 | 全部閉じる。**別の AutoCAD（2つ目の起動）**で 05_断面図 を開いておく。1つ目の AutoCAD で 01 と 05 を開いて `KR` → 名前 `使用中テスト` → 記録。1つ目で 01 と 05 を閉じてから `TZ` → 「使用中テスト」を選んで［開く］ | 05_断面図 が読み取り専用で開き、「ほかの人が使用中のため読み取り専用で開いた図面」と表示されるか（途中で AutoCAD の確認画面が出た場合は、その内容を教えてください） |
| 12 | `TZ` → 記録をダブルクリック | すぐに開くか |
| 13 | 記録の図面がすべて開いている状態で `TZ` | ［開く］が押せない（灰色）になっているか |
| 14 | `TZ` → 記録を選んで［この記録を削除］ | 1回目は注意、2回目で削除され、一覧から消えるか |
| 15 | `TZ` →［保存先を変更...］→ フォルダを選ぶ | Windows のフォルダ選択画面が出て、選んだあとダイアログに戻り、保存先の表示が変わるか（その保存先には記録が無いので一覧は空になる） |
| 16 | `KRS` →［初期値に戻す］→［閉じる］ | 保存先が初期値に戻るか。AutoCAD を再起動しても保存先の設定が残るか |
| 17 | 各ダイアログで［キャンセル］や Esc | 「中止しました」と出て、エラーにならないか |
| 18 | `-KIROKU` / `-TSUZUKI` / `-KIROKUSET` | 1.0.0 と同じコマンドラインの操作ができるか |

## まとめて確認

- AutoCAD を再起動したあとに `TZ` → Enter で、前回の記録が開くか（翌日の使い方）。
- 日本語のフォルダ名・ファイル名の図面でも、正しく記録・再開できるか。
- `U`（元に戻す）を押しても、図面に何も変化がないか（このツールは図面を変更しません）。

## 結果の伝え方

うまくいかなかった手順の番号と、コマンドラインのメッセージ（あれば画面の写真）を教えてください。ダイアログの見た目の好み（大きさ・並び・言葉）も遠慮なくどうぞ。

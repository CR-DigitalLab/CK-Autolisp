# KirokuTsuzuki 1.1.0 の lispcheck 検証結果（2026-09-28）

AutoCAD の代わりに `tools/lispcheck/lispcheck.py`（簡易シミュレータ 0.1.4）で動かした結果です。
図面を開く・前面にする・記録ファイルの読み書き・**ダイアログ**は、lispcheck の仮想機能で再現しています。
（ダイアログは見た目を再現せず、DCL の文法・キーの確認と、入力欄・一覧・ボタンの動作を再現）

テスト台本：[../lispcheck/test_kiroku.lsp](../lispcheck/test_kiroku.lsp)（自動チェック 24 項目、すべて合格）
記録：[テスト_レポート.txt](テスト_レポート.txt)（各ダイアログに表示された一覧・文言も記録されています）

## lispcheck 側で足したこと（0.1.4）

- **DCL ダイアログの簡易再現**：DCL の文法（括弧・引用符）とキーの確認、`new_dialog`・`set_tile`・`get_tile`・`mode_tile`・`action_tile`・リスト（`start_list`〜`end_list`）・`start_dialog`・`done_dialog` などを再現。操作は入力台本で「入力欄に値を入れる・ボタンを押す・一覧を選ぶ・ダブルクリック」を指定
- `vl-filename-mktemp` が AutoCAD と同じく一時フォルダのパス（拡張子つき）を返すようにした

## lispcheck では確かめられないこと（AutoCAD で確認）

- ダイアログの日本語が文字化けしないか（1.1.1 で DCL を ANSI で書き出すように変更。1.1.0 の UTF-8 では文字化けした）
- ダイアログの見た目（文字が切れないか、大きさ・並び）
- ［保存先を変更...］で Windows のフォルダ選択画面が出るか
- 実際に複数の図面が開くか、最後に前面になる図面が正しいか
- ほかの人が使用中の図面を開くときの AutoCAD の動き

# KirokuTsuzuki 動作確認手順

テスト用の図面セット：`図面セット/` の 5 つの DXF（各図面に、役割と「こうなれば正常」を書いてあります）

| 図面 | 役割 |
|---|---|
| 01_平面図 | いつもどおり開く図面（KR のとき前面にしておく） |
| 02_立面図 | 変更して保存しない図面 |
| 03_配置図 | TZ の前に開いておく図面 |
| 04_詳細図 | KR のあと名前を変える図面 |
| 05_断面図 | ほかの人が使用中の図面 |

AutoCAD で試す前に、lispcheck でできる範囲の確認は済ませてあります（[lispcheck結果/検証結果.md](lispcheck結果/検証結果.md)）。

## 準備

1. `図面セット` フォルダを、試しやすい場所（例：デスクトップ）にフォルダごとコピーする（元のファイルは残しておく）。
2. `APPLOAD` で `KirokuTsuzuki.lsp` を読み込む。
3. `KR`・`TZ`・`KRS` を打って、ほかのコマンドと重なっていないか確認（何か別のものが動いたら教えてください）。

## 確認の流れ

| # | 手順 | 見るところ |
|---|---|---|
| 1 | コピーした 01〜04 を開く。02_立面図 の円を少し動かす（保存しない）。新規図面（Drawing1）も1つ作る。最後に 01_平面図 を前面にする | ― |
| 2 | `KR` → Enter | 「前回」に図面 4 枚を記録、と出るか。02_立面図 が「保存していない変更がある図面」、Drawing1 が「記録できない図面」と表示されるか |
| 3 | `KR` → `N` → `現場A` → Enter | 「現場A」に記録、と出るか |
| 4 | `KR` → `N` → `a/b` | 「使えない文字」と出て、もう一度聞かれるか（Esc で抜ける） |
| 5 | `KR` → `N` → `現場A` → `N`（いいえ） | 上書きせず、もう一度聞かれるか（Esc で抜ける） |
| 6 | すべての図面を閉じる（02 は保存しない）。03_配置図 だけを開く | ― |
| 7 | `TZ` → Enter | 01・02・04 が開き、03 は二重に開かれないか。最後に 01_平面図 が前面になるか。「開いた図面 3 枚 / すでに開いていた図面 1 枚」と出るか |
| 8 | 全部閉じる。エクスプローラーで 04_詳細図 の名前を変える（例：04_詳細図_old）。どれか1枚だけ開いて `TZ` → Enter | 04_詳細図 が「見つからない図面」と表示され、ほかは開くか |
| 9 | 全部閉じる。**別の AutoCAD（2つ目の起動）**で 05_断面図 を開いておく。1つ目の AutoCAD で 01 と 05 を開いて `KR` → `N` → `使用中テスト`。1つ目で 01 と 05 を閉じてから `TZ` → Enter | 05_断面図 が読み取り専用で開き、「ほかの人が使用中のため読み取り専用で開いた図面」と表示されるか（途中で AutoCAD の確認画面が出た場合は、その内容を教えてください） |
| 10 | `TZ` → `L` → 番号 | 一覧が新しい順に出て、選んだ記録の図面が開くか |
| 11 | `KRS` → `L`（一覧）→ `D`（削除）→ 番号 → `Y` | 記録が削除されるか |
| 12 | `KRS` → `F` → 別のフォルダ（例：`D:\テスト\記録`）→ `KR` → Enter → `KRS` → `F` → `.` | 別フォルダに記録でき、`.` で元の保存先に戻るか。AutoCAD を再起動しても保存先の設定が残るか |
| 13 | 各コマンドの途中で Esc | 「中止しました」と出て、エラーにならないか |

## まとめて確認

- AutoCAD を再起動したあとに `TZ` → Enter で、前回の記録が開くか（翌日の使い方）。
- 日本語のフォルダ名・ファイル名の図面でも、正しく記録・再開できるか。
- `U`（元に戻す）を押しても、図面に何も変化がないか（このツールは図面を変更しません）。

## 結果の伝え方

うまくいかなかった手順の番号と、コマンドラインのメッセージ（あれば画面の写真）を教えてください。

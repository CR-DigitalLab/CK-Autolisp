# KirokuTsuzuki（キロク・ツヅキ）

開いている図面を記録しておき、あとでまとめて開き直す AutoLISP です。対応：AutoCAD 2027。

| コマンド | ショートカット | 内容 |
|---|---|---|
| `KIROKU` | `KR` | 開いている図面の一覧を記録する |
| `TSUZUKI` | `TZ` | 記録した図面をまとめて開く |
| `KIROKUSET` | `KRS` | 設定（保存先の変更・記録の一覧・削除） |

## 使い方

1. `APPLOAD` で `KirokuTsuzuki.lsp` を読み込む（UTF-8 で保存してあります）。
2. 作業を終えるとき：`KR` → Enter。「前回」として記録します。
   - `N` で名前を付けて記録（例：現場A）。同じ名前があれば上書きするか聞きます。
3. 作業を再開するとき：`TZ` → Enter。最後に記録したものをまとめて開きます。
   - `L` で記録の一覧から番号で選べます。

## 動き

- **記録するのは図面の場所だけ**です。図面そのものは保存しません。
  - 保存していない変更がある図面は、記録したうえで名前を表示して知らせます。
  - 一度も保存していない図面（Drawing1 など）は場所が無いため記録できず、その旨を表示します。
- 記録しても図面は閉じません。
- `TZ` では：
  - すでに開いている図面は二重に開きません。
  - 見つからない図面（移動・削除）は飛ばして、最後にまとめて表示します。
  - ほかの人が使用中の図面は読み取り専用で開いて、その旨を表示します。
  - 最後に、記録したときに前面だった図面を前面にします。

## 設定（KRS）

| 項目 | 内容 |
|---|---|
| 保存先(F) | 記録ファイルの保存先。初期値は AutoCAD のユーザー設定フォルダの中（`…\KirokuTsuzuki\`）。共有フォルダにすると別の PC でも使えます。「.」で初期値に戻す |
| 一覧(L) | 記録の一覧（新しい順・日時・枚数） |
| 削除(D) | 記録を番号で選んで削除 |

記録ファイルは `名前.krk`（UTF-8 のテキスト）です。保存先と最後に使った記録の名前は、ユーザーごとに記憶されます。

## 作成ルールへの対応

- Undo グループ（図面は変更しないため、Undo しても変化なし）
- 完了時に結果（記録・開いた枚数、未保存・見つからない・読み取り専用の図面）を表示
- ショートカット（KR / TZ / KRS）
- システム変数は変更しない
- Esc・選択なしでも安全に終了

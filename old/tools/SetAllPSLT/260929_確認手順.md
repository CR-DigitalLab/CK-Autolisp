# SetAllPSLT ver2 動作確認手順

テスト図面：`SetAllPSLT_test.dxf`（各区画に「期待：〜」を書いてあります。見出しはロック画層）

## 準備

1. テスト図面を開き、DWG として別名保存（元の DXF は残す）。
2. `APPLOAD` で `SetAllPSLT_ver2.lsp` を読み込む（ver1 を読み込んでいる場合は、AutoCAD を開き直してから）。読み込み時に「[… ver2] 読み込み完了」と出るか。

## 確認の流れ

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01 | SAP → 1 | 「完了」。レイアウト1〜3 それぞれで `PSLTSCALE` を打つと 1。実行前のレイアウトに戻っている |
| 01 | SAP → 0 | 同じく全部 0 |
| 02 | SAP → 値の入力で Esc | 今のレイアウトのまま。`CMDECHO` が実行前の値 |
| 03 | SAP → 5 | 「入力値が不正です」。何も変わらない |
| 全体 | 実行後に U を1回 | PSLTSCALE が実行前に戻る |

## ver1 と比べたいとき

同じ図面の別コピーで `SetAllPSLT.lsp`（ver1）を読み込み、同じ手順で結果が同じか（違うのは Esc・エラーのときの後始末と表示だけ）を見てください。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージを教えてください。

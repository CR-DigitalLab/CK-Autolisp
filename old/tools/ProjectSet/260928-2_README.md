# ProjectSet（プロジェクトセット）

開いている図面を記録しておき、あとでまとめて開き直す AutoLISP です。記録と再開を1つのダイアログで行います。対応：AutoCAD 2027。
（チコさん作。[KirokuTsuzuki](../KirokuTsuzuki/README.md) の KR・TZ を1画面にまとめたもの）

| コマンド | ショートカット | 内容 |
|---|---|---|
| `PROJECTSET` | `PJ` | 記録・再開・名前変更・削除・保存先の変更 |

## 使い方

1. `APPLOAD` で `ProjectSet.lsp` を読み込む（ANSI＝Shift-JIS で保存してあります）。
2. `PJ` でダイアログが開きます。
   - **記録する（上半分）**：今開いている図面の一覧。名前を確かめて［記録する］（または名前欄で Enter）。記録したらダイアログは閉じます。
   - **記録から開く（下半分）**：左で記録を選ぶと、右にその図面が出ます。Enter（［開く］）またはダブルクリックで開きます。
3. 名前の初期値は「選んでいる記録の名前」です（記録が無いときは「日付_プロジェクトセット」）。
   - そのまま［記録する］で、選んでいる記録を今の図面で更新します（確認なし）。
   - 別の既存の名前にすると、もう一度［記録する］を押したときに上書きします。
   - 新しく記録するときは、名前を変えてください。
4. ダイアログを開くと、いつも「最後に使った記録」が選ばれています。

## 動き

- 記録するのは図面の場所だけです。図面そのものは保存しません。
- 一度も保存していない図面（Drawing1 など）は記録できません。
- 開くとき：
  - すでに開いている図面は二重に開きません。
  - 見つからない図面は飛ばします。
  - ほかの人が使用中の図面は読み取り専用で開きます。
  - 最後に、記録したときに前面だった図面を前面にします。
- 1図面だけを開くモード（SDI=1）では、［開く］は押せません（記録はできます）。
- 記録ファイルは `名前.pjs`。保存先の初期値は AutoCAD のユーザー設定フォルダの中（`…\ProjectSet\`）。

## 作成ルールへの対応

- Undo グループ（図面は変更しないため、Undo しても変化なし）
- 完了時に結果をコマンドラインに表示
- ショートカット（PJ）
- システム変数は変更しない
- Esc・キャンセルでも安全に終了
- LSP ファイルとダイアログの定義（DCL）は ANSI（Shift-JIS）。DCL は実行時に一時フォルダへ書き出して、終了時に削除

## 更新履歴

- 1.1.1（2026-09-28）
  - エラーのときに「どこで起きたか」を表示するようにした。

  - 記録したらダイアログを閉じるようにした。
  - 名前の初期値を「選んでいる記録の名前」にした。
  - 名前変更後もその記録が選ばれたままにした。
  - 同じ日時の記録は名前順に並べるようにした。

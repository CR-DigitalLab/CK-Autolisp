# note で無料公開中の LISP　ver2 修正一覧（2026-09-29、09-30 更新）

今回 `_ver2` にした LISP は **15本** です。
- どれも、コマンド名・ショートカット・質問の順番は変えていません。
- 元のファイル（公開中の版）は、同じフォルダに元の名前のまま残しています。

## 不具合の修正を含むもの（7本）

| LISP | 修正内容 |
|---|---|
| [LockAllVP](LockAllVP/) | ・ロックされた画層にビューポートがあると、途中でエラーになって止まっていた → そのビューポートを飛ばし、その数を知らせる<br>・終わったあと、実行前のレイアウトに戻るようにした（ver1 は最後のレイアウトのままだった。チコさんの判断で決定）<br>・Undo グループを付けた（U 1回で戻る）<br>・ロックした数を表示<br>・読み込み時にコマンド名を表示 |
| [ClipCopy](ClipCopy/) | ・途中でエラーになると、選んだ図形が消えたままになるおそれがあった → 自動で実行前に戻す<br>・Undo グループを付けた<br>・英語版以外でも確実に動く書き方にした<br>・読み込み時にコマンド名を表示 |
| [Load_All_Lsp](Load_All_Lsp/) | ・フォルダ内の LISP が1つでもエラーになると、残りが読み込まれなかった → 失敗したものは「読み込み失敗」と理由を表示し、続きを読み込む<br>・ファイル名は `_ver2` を付けず元の Load_All_Lsp.lsp のまま（自分のファイル名で場所を探すため。`ver2` フォルダに置いた） |

| [CHAMFER+](CHAMFER+/) | ・Esc・エラーのとき、Undo グループが閉じないことがあった<br>・作成時のメモと、使っていないコードのコメントを整理<br>・読み込み時にコマンド名を表示 |

## 確認のしかた

- 15本とも、ver1 と ver2 を同じテスト図面・同じ操作で lispcheck にかけて比べた。
  - 普段の動きは同じ。違いは、足した表示とエラー時の後始末だけ。
  - LockAllVP だけは例外。「終わったあと実行前のレイアウトに戻る」という動きの変化を、チコさんに決めてもらったうえで入れた。
  - lispcheck で再現できない処理（分解・面取りなど）は動かせていないので、実際の AutoCAD で確かめる必要がある。
- 実際の AutoCAD での確認手順は、各フォルダの `test/確認手順.md` にある。
- 記事で「IJCAD2025(STD)でも動作確認済み」としているものについて、今回足した命令を、IJCAD で動いた実績のあるほかの LISP で使われているものと照らし合わせた。
  - 使われていないのは、ClipCopy・Load_All_Lsp・LockAllVP の一部だけ。一般的な書き方なので、ほぼ心配はない。
  - IJCAD があれば、この3本を一度試しておくと安心。
- 2026-09-30 チコさんの確認で分かったこと：
  - Load_All_Lsp：`_ver2` の名前では AutoCAD で「パスが取得できませんでした」になった → ファイル名を元に戻した。
  - XForce：IJCAD では ver1 から動かなかった → IJCAD 非対応とした。
- 2026-09-30 各 LSP 先頭の修正メモを体言止めに書き直した（中身の動きは変えていない）。

# RANDOMBNAME ver2 動作確認手順

テスト図面：`RANDOMBNAME_test.dxf`（各区画に「期待：〜」を書いてあります。見出しはロック画層）

## 準備

1. テスト図面を開き、DWG として別名保存（元の DXF は残す）。
2. `APPLOAD` で `RANDOMBNAME_ver2.lsp` を読み込む（ver1 を読み込んでいる場合は、AutoCAD を開き直してから）。読み込み時に「[… ver2] 読み込み完了」と出るか。

## 確認の流れ

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01 | 4個を窓で選んで RBN | 「完了: 2 個」。机・椅子の定義名が A$C… に変わる（BLOCK コマンドの一覧で確認）。見た目は変わらない |
| 02〜04 | それぞれ選んで RBN | 回転・尺度、属性の値、入れ子の中身が変わらない |
| 05 | ロック画層のブロックを選ぼうとする | 選べない（ロック画層） |
| 06 | RBN → 何も選ばず Enter／選択中に Esc | 「ブロックが選択されませんでした」／Esc のあと `CMDECHO` と打って値が実行前のまま |
| 全体 | 実行後に U を1回 | 名前が全部元に戻る |

## ver1 と比べたいとき

同じ図面の別コピーで `RANDOMBNAME.lsp`（ver1）を読み込み、同じ手順で結果が同じか（違うのは Esc・エラーのときの後始末と表示だけ）を見てください。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージを教えてください。

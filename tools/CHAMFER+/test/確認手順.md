# CHAMFER+ ver2 動作確認手順

テスト図面：`CHAMFER+_test.dxf`（各区画に「期待：〜」を書いてあります。見出しはロック画層）

## 準備

1. テスト図面を開き、DWG として別名保存（元の DXF は残す）。
2. `APPLOAD` で `CHAMFER+_ver2.lsp` を読み込む（ver1 を読み込んでいる場合は、AutoCAD を開き直してから）。読み込み時に「[… ver2] 読み込み完了」と出るか。

## 確認の流れ

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01〜03 | CF → 2本の線（またはポリラインの角）を選ぶ | 表示の面幅（最初は15）で面取り |
| 04 | CF → F → 20 | 以後の面幅が 20。閉じて開き直しても 20 |
| 05 | 1本目を選んだあと Esc → U を1回 | エラーにならない。U でそれまでの面取りが1つ戻る |
| 06 | ロック画層の線 | 面取りできない（エラーで止まらない） |

## ver1 と比べたいとき

同じ図面の別コピーで `CHAMFER+.lsp`（ver1）を読み込み、同じ手順で結果が同じか（違うのは Esc・エラーのときの後始末と表示だけ）を見てください。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージを教えてください。

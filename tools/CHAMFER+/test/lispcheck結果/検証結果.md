# CHAMFER+ ver2 の lispcheck 検証結果（2026-09-29）

lispcheck 0.1.8 で、ver1（公開中）と ver2 を同じテスト図面・同じ操作で動かし、コマンドラインの表示・図面の変化・システム変数を比べた。

- Esc：ver1 と同じ表示・結果（面取り距離の初期値15が入るのは ver1 と同じ・意図どおり）
- 面取り自体は lispcheck では再現できない
- ChikoLispCheck 1.0.6：× なし（△ はコマンドの目的として変えるシステム変数のみ）

**結論**：普段の動きは ver1 と同じ。違いは、Esc・エラーのときの後始末と、足した表示だけ。

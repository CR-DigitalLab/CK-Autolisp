# YokeruText 動作確認手順（2.0.0）

テスト図面：`YokeruText_test.dxf`（24区画。各区画の見出しの下に「期待：〜」として正常な結果を書いてあります）

AutoCAD で試す前に、簡易シミュレータ lispcheck でできる範囲の確認は済ませてあります（[lispcheck結果/検証結果.md](lispcheck結果/検証結果.md)）。特に AutoCAD で見てほしいのは、寸法の文字（区画06・10・21・22）・マルチ引出線（区画23・24）・マルチテキスト（区画04・12）・終了後の選択状態・UCS（区画19）・AutoCAD の Undo です。

見出しと区画の枠は**ロック画層**（`YK_見出し`・`YK_区画`）に置いてあるので、全体を選んでも動きません（結果の「ロック画層」の件数に入ります）。

## 準備

1. `YokeruText_test.dxf` を開き、DWG として別名保存（テストで変わるため、元の DXF は残しておく）。
2. `APPLOAD` で `YokeruText.lsp` を読み込む。
3. 設定を初期値にしておく：`YKS` → `R`（初期値）→ Enter。

## 確認の流れ

基本は「区画を窓選択 → `YK`」または「`YK` → 区画を窓選択 → Enter」。確認は出ずにすぐ動きます。結果を見たら `U`（元に戻す）で戻して次へ進むと、図面を汚さずに続けられます。

どの区画でも、終わったあと**動いた文字が選択状態（青いグリップ）になっているか**も見てください。

## まとめて確認

- 図面全体：何も選ばずに `YK` → Enter → `A`（図面全体）。結果の件数と、動いた文字が全部選択状態になるかを見る。
- Esc の確認：選択中に Esc → 「中止しました。」と出て、エラーにならないか。
- Undo の確認：実行したあとに `U`（AutoCAD の Undo）を1回 → 実行前の状態に戻るか（寸法の文字・マルチ引出線も）。
- 設定画面：`YKS` で余白・距離・方向数を変更 → AutoCAD を再起動しても設定が残っているか。`YK` → 何も選ばず Enter → `S` でも設定画面が開くか。

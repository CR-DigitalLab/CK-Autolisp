# YokeruText（ヨケルテキスト）

重なっている文字を、空いている場所へ自動で逃がす AutoLISP です。対応：AutoCAD 2027。

| コマンド | ショートカット | 内容 |
|---|---|---|
| `YOKERU` | `YK` | 文字の重なりを自動で避ける |
| `YOKERUSET` | `YKS` | 設定（余白・最大移動距離・探す方向の数） |

## 使い方

1. `APPLOAD` で `YokeruText.lsp` を読み込む（ANSI＝Shift-JIS で保存してあります）。
2. `YK` → 逃がしたい文字を選んで Enter。すぐに実行され、確認は出ません。
   - 先に文字を選んでから `YK` でも可。
   - 何も選ばずに Enter →「図面全体(A)／設定(S)／終了(X)」を選べます。
3. 終わると、**動いた文字がすべて選択状態**になります（まとめて画層を変える・確かめる用）。
4. 気に入らなければ `U`（AutoCAD の元に戻す）1回で、実行前に戻ります。

## 動かすもの・よけるもの

- 動かす：文字（TEXT）、マルチテキスト（MTEXT）、寸法の文字、マルチ引出線の文字。
  - 寸法：寸法の「文字の位置」だけを変えます。寸法線に沿って横へずらす方向を優先します。測った値・矢印・補助線はそのままです。
  - マルチ引出線：全体を動かしたあと、矢印の先だけ元の位置に戻します（指している場所は変わりません）。
- よける（障害物）：線・円・円弧・ポリライン・スプライン・ほかの文字・寸法・マルチ引出線・ブロック（大きな図枠は外形線だけ）。
- よけない：**ハッチ**、非表示・フリーズの画層の図形。
- 動かさない（件数を表示）：ロックされた画層の文字、非表示・フリーズの画層の文字、3D に傾いた文字、属性の文字、ブロックのマルチ引出線。
- 逃げ場がなかった文字はそのまま残し、件数だけ表示します。

## 仕組み（かんたんに）

- 図面の座標だけで判定するので、画面のズーム・UCS に左右されません。
- 周りの図形をマス目に振り分け、近くのものだけを比べるので、文字が多くても速く動きます。
- 元の位置のまわりを輪状に探し、「移動距離が短い」「文字の上下方向へ動く」場所を優先します。
- 込み合っている所から順に処理し、逃げ場がなかった文字は周りが動いた後にもう一度探します（最大3周）。

## 設定（YKS、または YK で何も選ばず Enter → S）

| 項目 | 初期値 | 内容 |
|---|---|---|
| 余白(C) | 0.25 | 文字どうし・図形との間に空ける余白（文字高さに対する割合） |
| 距離(D) | 6 | 最大でどこまで動かすか（文字高さの何倍） |
| 方向数(N) | 16 | 何方向を探すか（4〜64。多いほど細かく探すが遅くなる） |
| 初期値(R) | ― | すべて初期値に戻す |

設定はユーザーごとに記憶され、次回も引き継がれます。

## 注意

- 寸法の文字を動かしたときの寸法線の動きは、寸法スタイルの「文字の移動」の設定（寸法線ごと動く／引出線を付ける／文字だけ動く）に従います。
- 寸法・マルチ引出線の線は、自分の文字の障害物にはしません（ほかの文字の障害物にはなります）。
- 寸法の文字は、込み合っていると寸法線の反対側（下側など）へ回ることがあります。

## 作成ルールへの対応

- Undo グループ（エラー・Esc のときも正しく閉じる）
- 完了時に結果（対象・重なり・移動・逃げ場なし・処理時間）を表示
- ショートカット（YK / YKS）
- システム変数は変更しない（UCS・UCSFOLLOW・OSMODE に依存しない。計算はすべて図面座標）
- Esc・選択なしでも安全に終了（処理途中の Esc は全部元に戻す）
- コマンドを使わない作りのため、`*error*` 内の command-s も不要

## 更新履歴

- 2.0.0（2026-09-28）機能を絞って簡単にした。
  - やめたもの：引出線、固定画層、無視画層、背景マスク、実行後の確認、ハッチ・寸法・ブロックを障害物にするかの切り替え、寸法の文字・マルチ引出線を動かすかの切り替え。
  - いつも同じにしたもの：ハッチはよけない。寸法・ブロックはよける。寸法の文字・マルチ引出線の文字はいつも動かす。
  - 設定は「余白・最大移動距離・探す方向の数」の3つだけ。
  - 終了後、動いた文字をすべて選択状態にする（以前は逃げ場がなかった文字を選択していた）。
  - 不具合の修正：動かす対象にした寸法・マルチ引出線の線が、ほかの文字の障害物になっていなかった。
- 1.1.1（2026-09-28）LSP ファイルを ANSI（Shift-JIS）で保存するようにした（UTF-8 では日本語が文字化けするため）。
- 1.1.0（2026-09-27）寸法の文字・マルチ引出線の文字も動かせるようにした（設定 T / U）。マルチ引出線を障害物として正確に判定（引出線と文字を別々に）。寸法の矢印ブロックも障害物にした。空き場所の探し方を改良（最良の場所を確実に選ぶ）。
- 1.0.1（2026-09-27）回転角の記録が省略された文字も対象にした。ハッチ(H)ON のとき、ハッチの内側の文字も外へ逃がすようにした。
- 1.0.0（2026-09-27）最初の版。

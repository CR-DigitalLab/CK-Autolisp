# ProjectSet 動作確認手順

テスト用の図面セット：`図面セット/` の 5 つの DXF（各図面に、役割と「こうなれば正常」を書いてあります）

| 図面 | 役割 |
|---|---|
| 01_平面図 | いつもどおり開く図面（記録のとき前面にしておく） |
| 02_立面図 | 変更して保存しない図面 |
| 03_配置図 | ［開く］の前に開いておく図面 |
| 04_詳細図 | 記録のあと名前を変える図面 |
| 05_断面図 | ほかの人が使用中の図面 |

AutoCAD で試す前に、lispcheck でできる範囲の確認は済ませてあります（[lispcheck結果/検証結果.md](lispcheck結果/検証結果.md)）。

## 準備

1. `図面セット` フォルダを、試しやすい場所にフォルダごとコピーする（元のファイルは残しておく）。
2. `APPLOAD` で `ProjectSet.lsp` を読み込む（ANSI＝Shift-JIS で保存してあります）。
3. `PJ` を打って、ほかのコマンドと重なっていないか確認。

## 確認の流れ

| # | 手順 | 見るところ |
|---|---|---|
| 1 | 01〜04 を開き、新規図面（Drawing1）も1つ作る。01 を前面にして `PJ` | ダイアログの日本語が文字化けしていないか。上の一覧に図面が出て、Drawing1 に「※一度も保存していないため記録不可」。記録が無いので名前は「日付_プロジェクトセット」 |
| 2 | 名前を `現場A` にして、名前欄で Enter | **記録されてダイアログが閉じる**か（［開く］が動かないこと）。コマンドラインに「「現場A」に記録しました」 |
| 3 | `PJ` | 下の一覧で「現場A」が選ばれ、名前欄も「現場A」になっているか |
| 4 | そのまま［記録する］ | 確認なしで上書きされて閉じるか（選んでいる記録の更新） |
| 5 | `PJ` → 名前を `現場B` にして［記録する］ | 新しく記録されて閉じるか |
| 6 | `PJ` → 一覧で「現場A」を選ぶ → 名前欄を `現場B` に書き換えて［記録する］ | 「既にあります。もう一度…」と出て閉じないか。もう一度押すと上書きされるか |
| 7 | すべての図面を閉じ、03 だけを開いて `PJ` | **最後に使った記録が選ばれている**か。右に「※すでに開いています」（03） |
| 8 | Enter | ［開く］が動いて図面が開き、01 が前面になるか |
| 9 | 全部閉じる。04 の名前をエクスプローラーで変える。1枚開いて `PJ` | 右の一覧で 04 に「※見つかりません」。［開く］でほかは開くか |
| 10 | 別の AutoCAD で 05 を開いておき、1つ目で 01・05 を記録 → 閉じてから［開く］ | 05 が読み取り専用で開き、その旨が出るか（AutoCAD の確認画面が出たら教えてください） |
| 11 | `PJ` → 記録を選んで［名前変更］→ 新しい名前 → OK | 名前が変わり、**その記録が選ばれたまま**か |
| 12 | `PJ` → 記録を選んで［削除］を2回 | 1回目は注意、2回目で削除されるか |
| 13 | `PJ` → ［保存先の変更...］ | Windows のフォルダ選択画面が出て、戻ったあと保存先の表示が変わるか |
| 14 | `SDI` を 1 にして `PJ`（確認後 0 に戻す） | ［開く］が押せず、「1図面だけを開くモード…」と出るか。ダブルクリックでも開かないか。記録はできるか |
| 15 | 各所で［閉じる］や Esc | 「中止しました」と出て、エラーにならないか |

## 結果の伝え方

うまくいかなかった手順の番号と、コマンドラインのメッセージ（あれば画面の写真）を教えてください。

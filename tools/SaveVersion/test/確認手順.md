# SaveVersion 動作確認手順

テスト用の図面：`図面セット/` の DXF 9ファイル（各図面に、形式と「こうなれば正常」を書いてあります）

| ファイル | 形式 | 期待 |
|---|---|---|
| 01〜07 | DXF の R12・2000・2004・2007・2010・2013・2018 | 同じ形式の DXF のまま上書き保存される |
| 08 | バイナリ形式の DXF（2010） | 保存しないで「対応していません」と出る |
| 09 | 形式の書かれていない DXF | 保存しないで「形式を読み取れませんでした」と出る |

AutoCAD で試す前に、lispcheck でできる範囲の確認は済ませてあります（[lispcheck結果/検証結果.md](lispcheck結果/検証結果.md)）。

## 準備

1. `図面セット` フォルダを、試しやすい場所にフォルダごとコピーする（元のファイルは残しておく）。
2. `APPLOAD` で `SaveVersion.lsp` を「スタートアップ登録」に入れる（図面を開くたびに読み込まれるように）。
3. `SV` を打って、ほかのコマンドと重なっていないか確認。

## 確認の流れ

形式の確かめ方：保存したファイルを**メモ帳で開き**、`$ACADVER` の2行下を見る（AC1009＝R12、AC1015＝2000、AC1018＝2004、AC1021＝2007、AC1024＝2010、AC1027＝2013、AC1032＝2018）。DWG は、エクスプローラーで右クリック →［プロパティ］では分からないため、AutoCAD の DWG TrueView などで確かめるか、下の「DWG の確認」の手順で。

| # | 手順 | 見るところ |
|---|---|---|
| 1 | `01_DXF_R12.dxf` を開く | コマンドラインに「この図面：R12形式のDXF」と出るか |
| 2 | 四角を少し動かして `SV` | 「R12形式のDXFのまま上書き保存しました。」と出るか。メモ帳で AC1009 のままか |
| 3 | 02〜07 も同じように | それぞれの形式のままか |
| 4 | `05_DXF_2010.dxf` を開き、四角を動かして **Ctrl+S**（普通の上書き保存）→ メモ帳で形式を見る → 続けて `SV` | Ctrl+S で形式が変わった場合、`SV` で「（途中の上書き保存で…変わっていたのを、開いたときの形式に戻しました）」と出て AC1024 に戻るか |
| 5 | `08_バイナリDXF_2010.dxf` を開いて `SV` | 「バイナリ形式のDXFには対応していません。保存していません。」と出て、ファイルの更新日時が変わらないか（開けない場合はそのことを教えてください） |
| 6 | `09_形式不明のDXF.dxf` を開いて `SV` | 「ファイルの形式を読み取れませんでした。保存していません。」と出るか |
| 7 | 新規図面（Drawing1）で `SV` | 「まだ一度も保存していない図面です…」と出るか |
| 8 | 図面を読み取り専用で開いて `SV` | 「読み取り専用で開いている図面のため…」と出るか |

## DWG の確認

DWG はこちらで作れないため、AutoCAD で作ってください。

1. どれかの図面を開き、`名前を付けて保存` で「AutoCAD 2010/LT2010 図面」を選んで `2010形式.dwg` として保存 → 閉じる。
2. `2010形式.dwg` を開く →「この図面：2010形式のDWG」と出るか。
3. 少し変更して `SV` →「2010形式のDWGのまま上書き保存しました。」と出るか。
4. 閉じて DWG TrueView（または AutoCAD の `名前を付けて保存` 画面の形式の表示）で、2010 形式のままか確認。
5. 同じ図面で、変更 → Ctrl+S → `SV` の順に行い、手順4と同じく 2010 形式に戻るか。
6. 2013・2018・2000 形式でも同じように（時間があれば）。

## AutoCAD LT で使える場合

LT 2024 以降があれば、同じ手順で `SV` が動くかを見てください（LT で使えない関数は使っていないつもりです）。

## 結果の伝え方

うまくいかなかった手順の番号と、コマンドラインのメッセージ（あれば画面の写真）を教えてください。

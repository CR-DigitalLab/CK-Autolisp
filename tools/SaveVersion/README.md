# SaveVersion（セーブバージョン）

図面を「今の形式のまま」上書き保存する AutoLISP です。2010形式の DWG なら 2010形式の DWG、DXF なら同じ版の DXF で保存します。対応：AutoCAD 2027（AutoCAD LT 2024 以降でも使える作り）。

| コマンド | ショートカット | 内容 |
|---|---|---|
| `SAVEVERSION` | `SV` | 今の形式のまま上書き保存 |

## なぜ必要か

AutoCAD の上書き保存（Ctrl+S・QSAVE）は、開いた図面の形式ではなく、オプションで決めた既定の形式（通常は最新の 2018 形式）で保存します。古い形式の図面や DXF を受け取って直し、そのまま返すと、知らないうちに形式が変わり、相手のソフトで開けないことがあります。

## 使い方

1. `APPLOAD` で `SaveVersion.lsp` を読み込む（ANSI＝Shift-JIS で保存してあります）。
   - **おすすめ**：`APPLOAD` の「スタートアップ登録」に入れておく。図面を開くたびに読み込まれ、**開いたときの形式を覚えます**。途中でうっかり Ctrl+S を押して形式が変わっても、`SV` で開いたときの形式に戻せます。
2. 保存したいときに `SV`。確認なしで、すぐに上書き保存します。
3. 結果がコマンドラインに出ます（例：「2010形式のDWGのまま上書き保存しました。」）。
   - 読み込んだときにも「この図面：2010形式のDWG」のように表示されます。

## 対応している形式

| 種類 | 形式 |
|---|---|
| DWG | 2000・2004・2007・2010・2013・2018 |
| DXF（テキスト形式） | R12・2000・2004・2007・2010・2013・2018 |

次の場合は**保存せずに知らせます**（無理に保存しない）。
- 形式を読み取れない図面（壊れたファイル、形式の書かれていない DXF など）
- この AutoCAD では保存できない形式（R14 以前の DWG、これから出る新しい形式）
- バイナリ形式の DXF
- まだ一度も保存していない図面、読み取り専用で開いている図面
- テンプレート（DWT）など DWG・DXF 以外
- 保存に失敗したとき（ほかの人が使用中・書き込み禁止の場所など）は、エラーで止まらずに理由を表示します。

## 仕組み（かんたんに）

- 図面ファイルの先頭を読んで形式を調べます（DWG は先頭の6文字、DXF は `$ACADVER` の値）。
- 保存は AutoCAD の「名前を付けて保存」と同じ仕組み（ActiveX の SaveAs）で、同じ場所・同じ名前・同じ形式を指定して行います。コマンドを使わないので、画面のダイアログやシステム変数（FILEDIA など）の設定に左右されません。
- 保存したあと、もう一度ファイルを読み、形式が合っているか確かめてから結果を表示します。
- DXF の小数の桁数は AutoCAD の初期値（16桁）で保存します。

## 作成ルールへの対応

- **あらゆる環境で安定**：システム変数を変えない。コマンドを使わない。分からない形式は保存せずに知らせる。
- **シンプル**：コマンド1つ、確認なし、設定なし。
- **LT 2024 以降**：LT でも使える関数だけで作っています（ActiveX の SaveAs は LT 2024 以降で使えます）。
- Undo グループ：図面の中身を変えないため使っていません（保存は元に戻す対象ではありません）。
- 完了時に結果を表示／ショートカット（SV）／Esc・エラーでも安全に終了。

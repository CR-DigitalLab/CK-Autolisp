# CopyBlock ver2 動作確認手順

テスト図面：`CopyBlock_test.dxf`（各区画に「期待：〜」を書いてあります。見出しはロック画層）

## 準備

1. テスト図面を開き、DWG として別名保存（元の DXF は残す）。
2. `APPLOAD` で `CopyBlock_ver2.lsp` を読み込む（ver1 を読み込んでいる場合は、AutoCAD を開き直してから）。読み込み時に「… ver2 …」と出るか。

## 確認の流れ

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01 | CB → 机を選ぶ → Enter → 配置 | 「机_2」ができ、画層・回転・尺度・属性「D-001」が引き継がれる |
| 02 | CB → 棚 → 「棚_新」 | 「棚_新」ができる。色も引き継がれる |
| 03 | 既にある名前「机」 | 「既に存在します」。何も作られない |
| 04 | 線を選ぶ／選ぶときに Esc／配置で Esc | 「ブロックではありません」／エラーにならない／「配置がキャンセルされました」 |

## ver1 と比べたいとき

同じ図面の別コピーで `CopyBlock.lsp`（ver1）を読み込み、同じ手順で結果が同じか（違うのは Esc・エラーのときの後始末と表示だけ）を見てください。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージを教えてください。

# LPON・LPOFF ver2 動作確認手順

テスト図面：`LPON・LPOFF_test.dxf`（各区画に「期待：〜」を書いてあります。見出しはロック画層）

## 準備

1. テスト図面を開き、DWG として別名保存（元の DXF は残す）。
2. `APPLOAD` で `LPON・LPOFF_ver2.lsp` を読み込む（ver1 を読み込んでいる場合は、AutoCAD を開き直してから）。読み込み時に「… ver2 …」と出るか。

## 確認の流れ

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01 | LPOFF → 壁・家具の線 | 「合計 2 個の画層を非印刷に設定しました」。画層管理で「印刷しない」 |
| 02 | LPON → 補助線 | 補助線が印刷可能に |
| 03 | Defpoints も選んで LPON | 「Defpoints…スキップしました」 |
| 04 | ロック画層の図形 | その画層の印刷設定も変わる |
| 05 | 何も選ばない／Esc／U | 「選択されませんでした」／エラーにならない／U 1回で元に戻る |

## ver1 と比べたいとき

同じ図面の別コピーで `LPON・LPOFF.lsp`（ver1）を読み込み、同じ手順で結果が同じか（違うのは Esc・エラーのときの後始末と表示だけ）を見てください。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージを教えてください。

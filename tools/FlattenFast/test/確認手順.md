# FlattenFast ver2 動作確認手順

テスト図面：`FlattenFast_test.dxf`（各区画に「期待：〜」を書いてあります。見出しはロック画層）

## 準備

1. テスト図面を開き、DWG として別名保存（元の DXF は残す）。
2. `APPLOAD` で `FlattenFast_ver2.lsp` を読み込む（ver1 を読み込んでいる場合は、AutoCAD を開き直してから）。読み込み時に「… ver2 …」と出るか。

## 確認の流れ

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01〜03 | FTF → 全部選ぶ | 「○個のオブジェクトのZ座標を0にしました！」。プロパティで Z・高度・厚みが 0 |
| 04 | ロック画層の線 | 選べず、Z はそのまま |
| 05 | 何も選ばない／Esc／U | 「選択されませんでした」／「Error:」が出ない／U 1回で全部元に戻る |

## ver1 と比べたいとき

同じ図面の別コピーで `FlattenFast.lsp`（ver1）を読み込み、同じ手順で結果が同じか（違うのは Esc・エラーのときの後始末と表示だけ）を見てください。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージを教えてください。

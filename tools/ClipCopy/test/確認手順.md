# ClipCopy ver2 動作確認手順

テスト図面：`ClipCopy_test.dxf`（各区画に「期待：〜」を書いてあります。見出しはロック画層）

## 準備

1. テスト図面を開き、DWG として別名保存（元の DXF は残す）。
2. `APPLOAD` で `ClipCopy_ver2.lsp` を読み込む（ver1 を読み込んでいる場合は、AutoCAD を開き直してから）。読み込み時に「… ver2 …」と出るか。

## 確認の流れ

| 区画 | 手順 | 見るところ |
|---|---|---|
| 01 | CLC → 円の中心付近と右下を対角に指定 → PASTECLIP | 枠で切り取られた形が貼れる。元の図形は1本も消えていない |
| 02 | 同じく | ブロック・ハッチも切り取られて貼れる |
| 03 | ロック画層の線を含めて範囲指定 | エラーで止まらないか。止まった場合も「実行前の状態に戻しました」と出て、図形が消えたままにならないか |
| 04 | 何もない所を囲む／1点目で Esc | 「範囲内にオブジェクトがありませんでした」／エラーにならず OSMODE・CMDECHO が実行前の値 |
| 05 | CLC のあと U を1回 | 実行前の状態（ブロック定義 CLIP_… も消える） |

## ver1 と比べたいとき

同じ図面の別コピーで `ClipCopy.lsp`（ver1）を読み込み、同じ手順で結果が同じか（違うのは Esc・エラーのときの後始末と表示だけ）を見てください。

## 結果の伝え方

うまくいかなかった区画の番号と、コマンドラインのメッセージを教えてください。

■製品名
AcSortEditer

■ファイル名
AcSortEditer.lzh

■公開日
2007/09/10

■作者
OSADA

■概要
.NET Framework 2.0上で動作するAutoCAD、AutoCAD LT用一行文字一括整列編集ソフト。
AutoCAD2008対応

■機能
AutoCADの一行文字をテキストファイルに書き出し一括で編集できます。
書き出し時に文字を座標で上下左右の４方向からソートできます。
行を認識しソートできます。
文字コード順でソートできます。
編集用のエディターを登録することが出来ます。


■動作環境
Windows98/ME/2000/XP/Vista
.NET Framework 2.0がインストールされている必要があります。

■対応ソフト
AutoCAD2000i-2008　,　AutoCAD LT2000i-2008

■インストール

※以前のバージョンを設定済みであれば解凍したファイルを上書きコピーしてください。

詳しくはヘルプを見てください。

① .NET Framework 2.0のインストール
	http://www.microsoft.com/japan/msdn/netframework/downloads/
	下記2つがインストールされている必要があります。

	(1) Microsoft .NET Framework 2.0
	(1)はOSがVista又はAutoCAD2007以降の場合は必要なし。

	(2) Microsoft .NET Framework 2.0 日本語 Language Pack

	Microsoftの下記サイトからダウンロードしてインストールしてください。

	http://www.microsoft.com/japan/msdn/netframework/downloads/

	こちらからもダウンロードできます。
	(1) .NET Framework Version 2.0 再頒布可能パッケージ
	dotnetfx.exe 22.4MB
	http://www.microsoft.com/downloads/details.aspx?familyid=0856EACB-4362-4B0D-8EDD-AAB15C5E04F5&displaylang=ja
	(2) .NET Framework 2.0 日本語 Language Pack

②AcSortEditerのインストール
	※ツールボタンの登録が必要です。
	(1) AcSortEditer.lzhを任意のフォルダに解凍します。
	(2) AutoCADを起動し、サポートファイルの検索パスに解凍先のパスを
	    追加します。
	(3) menuloadコマンドでAcSortEditer.mnuをロードします。
	(4) ツールボタンが登録されて完了です。

	※以前のバージョンを設定済みであれば解凍したファイルを上書きコピーしてください。

■アンインストール
フォルダごと削除して下さい。

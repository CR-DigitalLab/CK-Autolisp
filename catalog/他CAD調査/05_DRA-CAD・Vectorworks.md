## 確認できなかった・除外した理由

- **AutoCAD にすでにあるため除外**：DRA-CAD の文字整列・文字原点揃え（TEXTALIGN）、文字囲み（Express の TCIRCLE）、破断線（Express の BREAKLINE）、モクモクペン（REVCLOUD）、データ整理（OVERKILL・PURGE）、線分1本化（JOIN）、連続延長・カット（TRIM・EXTEND の複数選択）、重ね合わせ表示・図面比較（DWG比較）、表示レイヤ範囲指定（LAYISO）、レイヤ一覧（LAYWALK）、属性のインポート（DesignCenter・画層状態の読み込み）、リストから印刷・一括変換（PUBLISH・DWG TrueView）、部品リスト（COUNT）、ラベル集計（データ書き出し）、二点間中央スナップ（M2P）、表示範囲呼出（VIEW）、クロスライン選択（フェンス）、属性・書式コピー（MATCHPROP）。Vectorworks の Offset の各モード（OFFSET の通過点・消去オプション）、Duplicate Array・Duplicate Along Path（ARRAY・ARRAYPATH）、Move by Points の Distribute（COPY の配列［フィット］）、Previous Selection、Select Coincident Objects（選択の循環）、Hide／Show Selected Only（HIDEOBJECTS・ISOLATEOBJECTS）、Gray Others（LAYISO のフェード）、Visibility ツール（LAYOFF など）、Saved Views（画層の状態付きのビュー）、Publish（PUBLISH）、Tape Measure（MEASUREGEOM の累積）、Align/Distribute Leader Lines（MLEADERALIGN）、Create Similar Object（ADDSELECTED）、Make All Attributes by Class（SETBYLAYER）、Check Spelling・Find-Replace・大文字小文字（SPELL・FIND・TCASE）、Custom Selection（FILTER で条件を名前付きで保存できるので、差が小さい）。
- **差が小さい・使い道が限られるため除外**：Smart Points・Smart Edge（オブジェクトスナップトラッキングや FROM でほぼ代わりになる）、DRA-CAD のドラフタ（UCS や SNAPANG）、プレゼン矢印・基本図形・注記（ポリラインやマルチ引出線で十分）、寸法線の足出し（寸法のプロパティで変えられる）、絞込選択・除外選択、属性変更の「連続」（空いている画層番号へ振る。番号で画層を管理する DRA 特有の仕組み）、文字流し込み、矩形変形、Symmetry Label、Protractor。
- **分野に寄っているため除外**：DRA-CAD の建築記号・構造図・電気設備・施工図・木造・法規（建ぺい率・斜線・日影・壁量など）、材料記号線上配置、通り心、寸法線自動作図（建物の形を前提にしている）、領域作成・建具表。Vectorworks の Wall・Space・Landscape・Spotlight・ConnectCAD 関連、Interior Elevation Marker、Grid Line、Create Objects from Shapes（壁やスラブなどを作るのが主な用途）。3D・レンダリング・クラウド・AI 関連もすべて除外。
- **確認しきれなかったもの**：DRA-CAD の「マクロ（MACRO）」は、DRA-CAD 自身の操作を記録・実行する仕組みで、LISP の題材にはならないため中身は調べていません。Vectorworks の Data Tag・Revision Cloud と改訂の連動・Title Block Manager・Data Visualization・Callout の注記データベース・Graphic Legend は、Design Suite 系（Fundamentals ではない）の機能です（コマンド・ツール比較表 2025 で確認）。依頼に名前が挙がっていたので表には入れました。Vectorworks 2026 の新機能の個別ページは確認していません（2025 のヘルプが基準）。
- **出典**：DRA-CAD リファレンスの全コマンドの目次は https://www.pivot.co.jp/manual/dracad/reference.html 、Vectorworks の製品別のコマンド・ツール一覧は https://app-help.vectorworks.net/2025/eng/assets/docs/Commands_Tools2025.pdf 。

# 次回見直しメモ

次に調査・採点を見直すときに、まとめて直す項目の控えです。

## 採点の前提（共通）

- 点数はすべて「使う前に、説明文など外から見て付けた**参考点数**」。
- アイデア・機能の見込みを示すもので、**動作の速さ・使いやすさ（手数の少なさ）・堅牢さ（安定性）は含まない**。これらはコード解析や試用で別途評価する。
- 「標準機能に似たものがある」だけで非代替性を下げない。**手数・速さ・対象範囲（文字だけ／寸法も等）の違い**を確認してから判断する。

## 見直し対象

| ツール（作者） | 誤っていた判断 | 正しい理解 | 見直しの方向 |
|---|---|---|---|
| DWG→DXF一括変換（チコ） | DWGCONVERTで代替可 | DWGCONVERTはDWGのバージョン変換のみで、DXFへの一括変換はできない | 非代替性を上げる |
| BackGroundText（チコ） | TEXTMASK等で代替可 | TEXTMASKは文字のみ。文字と寸法の背景マスクを1回でまとめて設定できる点、よく行う操作を少ない手数で行える点が価値 | 非代替性・時短効果を上げる |
| FlattenFast（チコ） | FLATTENで代替可 | FLATTENは大量の図形で遅い。処理の速さそのものが価値 | 非代替性を上げる |
| ZeroByLayer（チコ） | ボタン操作で代替可 | 現在画層0＋作成プロパティByLayerへの復帰は標準では複数操作。1回で済む手数の少なさが価値 | 非代替性・時短効果を上げる |

## 同じ誤りが他にもありそうな箇所（次回チェック）

- 評価メモに「〜で代替可」「標準で可」と書かれている行は、手数・速さ・対象範囲の違いを見落としている可能性がある。
- 特に Express Tools 相当の機能（TEXTMASK、FLATTEN、TXT2MTXT、BURST など）と比較した行。

## AutoCAD の新機能を踏まえた見直し（2026-09-27 追記）

詳細は [AutoCAD標準の検図機能_2027.md](AutoCAD標準の検図機能_2027.md) と [AutoCAD新機能まとめ_2019-2027.md](AutoCAD新機能まとめ_2019-2027.md)。

### 採点の前提に追加すること

- 非代替性は「**AutoCAD 2027（最新版）の標準機能**」を基準に判断する。あわせて「2026以前のユーザーには有効」など、**版による違い**を評価メモに書く。
- 標準機能の**対象外の部分**（ブロック内部・Z≠0・複数図面の一括処理・結果の一覧／CSV出力・LTで使えるか）で差があれば、非代替性を下げすぎない。

### 見直し対象（テーマ単位）

| テーマ | 関係する新機能 | 見直しの方向 |
|---|---|---|
| T08 検図：傾き・隙間・重なり | Geometry Cleanup（2027・LT可）、OVERKILL、PURGE | 単純な「傾き・隙間の検出」は非代替性を下げる。座標の端数・ブロック内・一括・レポート出力を持つものは維持 |
| T19 ブロックの置換・自動ブロック化 | Smart Blocks：検索して変換（2025〜2026・LT可）、検出（2025〜2026） | 「同じ形を探してブロック化」系は非代替性を下げる |
| T16 数量拾い・集計表 | COUNT（範囲指定・SELECTCOUNT、2022〜2023・LT可） | 単純なブロック個数の集計は下げる。独自書式・自動更新・長さ面積の集計は維持 |
| T09 差分比較・雲マーク | COMPARE／XCOMPARE（2019〜2021）、Activity Insights | 単純な2図面比較は下げる |
| T01・T18 自動で画層に振り分け | 既定画層の変数群（MLEADERLAYER・VIEWPORTLAYER・TABLELAYER・REVCLOUDLAYER など、2025.1〜2027） | 引出線・VP・表・雲マークの自動画層化だけのものは下げる |
| T29 外部参照 | コネクテッド・リファレンス（2027・LT可） | 見つからない外部参照のパス修正だけのものは下げる |
| T10 お掃除 | PURGE の作り直し（2020） | 長さ0・空文字の削除だけのものは下げる |
| T20 自動トリム | クイックトリム・BREAKATPOINT（2021） | 1点分割・一発トリムだけのものは下げる |

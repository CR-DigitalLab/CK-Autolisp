# AutoCAD 新機能まとめ（2019〜2027）

調査日：2026-09-27。Autodesk公式ヘルプの「What's New」とコマンドリファレンスを中心に確認しました。見た目の変更ではなく、**新しくできるようになったこと**（自動検出・一括処理・AI・新コマンドなど）だけを集めています。合計 **123件**（2019〜2022：38件、2023〜2025：46件、2026〜2027：39件）。

目的：LISPのアイデアが標準機能と重なっていないかを確かめるための資料です。各機能に「関連テーマ」（アイデア集の T01〜T30）を付けています。

### 注意

- **名前の揺れ**：Smart Blocks の「検索して変換」は資料によって BCONVERT（2025）／BSEARCH（2026）、検出は DETECT（2025）／BDETECT（2026）と表記されています。版で名前が変わった可能性があり、確定していません。
- **試験提供（Tech Preview）** の機能は、今後変わったり無くなったりする可能性があります。
- **既存のLISP・スクリプトへの影響**：2027で PSOUT と EPS 書き出しが削除されました。2026からラスター画像がバックグラウンドで読み込まれるため、一括印刷のスクリプトで待ち処理が必要になる可能性があります（未検証）。
- 公式ブログは取得できなかったため、一部は検索結果の要約で確認しています（各表の備考を参照）。

### 特に強力な新機能 TOP5（この範囲）

1. **個数カウント COUNT（2022）** … ブロック集計・個数表・個数フィールド・数え間違い検出まで標準化。T16 系LISPの主な出番が減る（LT でも使える）。

3. **外部参照比較 XCOMPARE（2021）** … 外部参照の変更を自動で検知して差分を改訂雲表示。これまで手段がほぼ無かった領域。

5. **トリム／延長クイックモード＋BREAKATPOINT（2021）** … 境界選択不要の一括トリムと1点分割が標準化。定番の「一発トリム」「1点分割」LISPが不要に。

### 特に強力な新機能 TOP5（この範囲）

1. **AutoLISP が AutoCAD LT で動く（2024）**：LISP ツールの配布先が LT ユーザーまで一気に広がった。重なる機能ではなく「追い風」だが、LT 非対応関数（vlax-create-object など）を避ける設計が必要。
2. **Smart Blocks: Search and Convert / BCONVERT（2025、2025.1 で強化）**：「同じ形を全部探してブロック化」という、これまで LISP でしかできなかった処理が標準・LT でも使える。T19 系のアイデアは差別化が必要。
3. **Markup Import ＋ Markup Assist（2023 → 2024 → 2025 と毎年強化）**：赤ペン PDF・写真を重ね、AI が文字・雲マーク・取り消し線・「MOVE」等の指示まで認識して図面に反映。OCR・修正反映系（T09/T12/T30）の LISP とはっきり重なる（LT は不可）。
4. **Activity Insights（2024、2025 で版比較・開かずに閲覧）**：作業履歴の自動記録と版ごとの比較が標準に。リアクタでログを取る T01 系、比較系 T09 のアイデアは「Docs/クラウドを使わない社内運用向け」などに絞る必要あり。
5. **Count の範囲指定＋SELECTCOUNT（2023）**：部屋・範囲ごとの個数集計が LT でも標準でできる。T16 の単純な「範囲内の個数を数える」LISP はほぼ不要に。集計表の自動更新や独自書式に価値を移すとよい。

（次点：MLEADERLAYER（2025.1）＝引出線の自動画層は、定番のリアクタ LISP を1変数で置き換えられる。Object Detection（2025 Tech Preview）は将来性大だが現状は検出対象が限定的。）

### 特に強力な新機能 TOP5（この範囲）

1. **ジオメトリ クリーンアップ（2027・LT も可）**：すき間・はみ出し・届いていない線・角度のずれを検出し、プレビューを見て1クリックで直せる。図面QC系 LISP（T08）の中心機能がほぼ標準になった。
2. **スマートブロック：検索して変換 BSEARCH（2026・LT も可）**：同じ形を全部探してブロック化し、文字違いは属性に変える。ブロック化・属性化 LISP（T19・T14）と大きく重なる。
3. **Autodesk Assistant の図面理解（2027〜2027.1・Tech Preview）**：標準ファイルとの比較、言葉での選択、数量・画層・属性・文字の問い合わせができる。チェック系・集計系 LISP（T07・T16・T18）と重なり始めた（ただし AI なので結果の確認が必要）。
4. **スマートブロック：検出して変換 BDETECT（2026、2026.1.1 で正式化・AutoCAD のみ）**：AI が「ブロックにすべき似た図形」を自動で見つける。多少形が違っても見つける点は LISP では真似しにくい。
5. **コネクテッド・リファレンス（2027・LT も可）**：見つからない外部参照だけを一覧にして一括で直せ、Forma 上では新しいパスを自動提案。外部参照パス修正 LISP（T29）の出番が減る。

（次点：Checkout（同時編集）、VIEWPORTLAYER / TABLELAYER / REVCLOUDLAYER などの「既定画層」変数群、Trusted Locations のサブフォルダ一括指定）

# T17 凡例・画層一覧の自動作成
> 一言で：図面で使っている画層・線種・ブロックを調べて、凡例や一覧表を自動で作図するアイデア。

## どんなアイデアか
設備図や土木図では「この線は給水管、この記号は照明」といった凡例が欠かせませんが、手で描くと図面内容とずれやすくなります。
このテーマのLISPは、図面で実際に使われている画層・線種・色・ブロックを読み取り、見本の線や記号付きの凡例・一覧表を自動で作ります。
画層の設定をExcelやファイルに書き出して、社内標準の確認や引き継ぎに使うものもあります。

## 仕組み（やさしい説明）
- 図面の中にある画層・線種・ブロックの「定義の一覧」（**シンボルテーブル**＝図面が持つ名簿）を順番に読み出す。
- 実際に図形が使われているものだけに絞り込み、使っていないものは凡例から外す。
- 1項目ごとに見本の線（その画層・線種で描く）やブロックを置き、横に名前や説明文を書いて表の形に並べる。
- レイアウトの**ビューポート**（用紙上の窓）に表示されている範囲だけを調べて、その窓用の凡例を作るものもある。
- 画層の名前・色・線種・線の太さをCSV（Excelで開ける文字データ）やスクリプト形式で書き出す。

## その他の注目例
- BLegend（英語圏・62）— 使用中のブロックの凡例表を作成
- BlkCatalog（英語圏・61）— 図面内ブロックの一覧表を作図
- AG Layer Color Legend（GitHub・55）— 画層の色の凡例を自動生成
- TRAERCUADROS（その他の地域・54）— ビューポート内の凡例・図枠をモデル空間へブロック化して集める
- LinCatalog / PatCatalog（英語圏・52/45）— 線種・ハッチパターンの見本表を作図
- 画層名ラベル（日本・46）— 線の上に画層名のラベルを記入
- LayerList（ヨーロッパ・45）— 画層の色・線太さ・線種をExcelへ出力
- lascr.lsp（日本・42）— 画層設定をスクリプト形式で書き出し、別図面で再現できる

## 今のAutoCAD標準機能との違い
- 標準でできる：画層プロパティ管理で画層の一覧を画面で見る（図面上に作図はできない）。
- 標準でできる：ブロックパレットやツールパレットでブロックを絵付きで選ぶ（図面上の一覧表にはならない）。
- 標準でできる：テーブルにブロックの絵を入れる（1セルずつ手作業）。
- 標準でできない：使用中の画層・線種から見本線付きの凡例を自動作図すること。
- 標準でできない：画層設定をExcelに書き出すこと（Express Tools などの補助が要る）。

## 独自アプローチのヒント
- 社内の画層名と「凡例に出す日本語名（例：WS-150 → 給水管 150A）」の対応表をExcelで持ち、凡例は日本語名で出す。
- 凡例を作ったあとに図面へ新しい画層が増えたら、「凡例に載っていない画層があります」と知らせるチェック機能。
- JIS の記号一覧に合わせた並び順・区分（電気・衛生・空調など）で自動分類して凡例を並べる。
- ビューポートごとに凍結されている画層を除いて、そのシート専用の凡例を作る（Viewport Legend の無料・簡易版）。
- 凡例の見本線の長さや文字サイズを、図面の縮尺（注釈尺度）に合わせて自動調整する。

## 自作の難しさ
★★（中級）— 画層の一覧を文字で並べるだけなら簡単ですが、見本線付きの表をきれいに並べたり、使用中のものだけに絞ったりするには一工夫が必要です。

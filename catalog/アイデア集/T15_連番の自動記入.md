# T15 連番の自動記入
> 一言で：クリックするたびに「1, 2, 3…」「A-01, A-02…」と番号を自動で増やして記入するアイデア。

## どんなアイデアか
部屋番号・機器番号・杭番号・図面番号など、図面には連番がたくさん出てきます。手で打つと番号の飛びや重複が起きがちです。
このテーマのLISPは、クリックした位置に番号を増やしながら文字やブロックを置いたり、既にある文字の番号を振り直したりします。
並び順（左上から順、線に沿った順など）で自動採番するもの、欠番・重複を見つけるものもあります。

## 仕組み（やさしい説明）
- 文字の中の「数字の部分」を見つけて取り出し、決まった数（増分）を足してから元の文字に戻す。「A-09」→「A-10」のように桁数もそろえる。
- 接頭辞・接尾辞（番号の前後に付く文字）や増分、桁数を最初に設定し、クリックのたびに次の番号を置く。
- 置く対象は普通の文字、**属性**（ブロックの値の欄）、引出線付きの丸番号（バルーン）など。
- 既存の文字を選んで、X・Y座標の順や、指定した線（ルート）に近い順に並べ替えてから番号を振る。
- 番号の列を読み取って、抜けている番号や同じ番号を探して知らせる。

## 今のAutoCAD標準機能との違い
- 標準でできる：自動番号（AUTONUMBER、Express Tools の TCOUNT）で選んだ文字に番号を付ける。
- 標準でできる：配列複写で同じ文字を並べる（ただし番号は増えない）。
- 標準でできない：クリックするたびに番号を増やして置くこと。
- 標準でできない：「A-09→A-10」のような桁そろえや英字の増分、属性への連番。
- 標準でできない：欠番・重複のチェック、線に沿った順番での採番。

## 独自アプローチのヒント
- 「①②③」の丸数字、「一、二、三」の漢数字、「イ、ロ、ハ」など日本の図面でよく使う番号形式に対応する。
- 通り芯記号（X1, X2… / Y1, Y2…）を柱位置から自動で振る、日本の構造図向けの採番。
- 途中に1つ番号を挿入したら、それ以降を自動で1つずつずらす「割り込み採番」。
- 番号を置くたびに画面の隅に「次は何番か」をプレビュー表示し、間違いを減らす。
- 複数レイアウト・複数図面をまたいで通し番号を管理し、図面間の重複を防ぐ。

## 自作の難しさ
★（簡単）— 数字を取り出して足して置くだけなら入門向きです。桁そろえ・英字・並べ替えまで入れると★★程度になります。

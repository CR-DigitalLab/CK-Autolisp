# T13 図形と数値の連動（フィールド・面積表）
> 一言で：図形の面積や長さを文字・表に「つなげて」おき、図形を直すと数字も自動で直るようにするアイデア。

## どんなアイデアか
部屋の面積や敷地の区画面積を文字で書き込んだあと、図形を少し修正すると数字が古いまま残ってしまう——これがよくある困りごとです。
このテーマのLISPは、面積・長さ・周長などの数値を図形と結びつけ、図形が変わると文字や表の数字も追いかけて変わるようにします。
複数の部屋の合計面積、区画ごとの面積表、線の各区間の長さ記入など、「測って書く」作業をまとめて自動化するものが中心です。

## 仕組み（やさしい説明）
- **フィールド**（文字の中に埋め込める「自動で値が入る欄」）を使い、図形の面積や長さを参照させる。図形を直して再作図すると数字が更新される。
- 複数の図形の合計は、フィールドの中に「A＋B＋C」という計算式を組み立てて入れる（Lee Mac の Areas to Field などの方式）。
- **リアクタ**（図形が変更されたことを見張って自動で処理を走らせる仕組み）で、図形を動かした瞬間に属性や文字を書き換える方式もある（gileCAD の TotalArea など）。
- 面積を**属性**（ブロックに付けられる文字情報の欄）に入れておき、あとで表やCSV（Excelで開ける文字データ）に書き出して集計する。
- 閉じた領域の中をクリックして境界を自動で見つけ、面積・周長を記入する方式もある（中国の MJArea など）。

## その他の注目例
- Area Object Link (AOL)（英語圏・75）— 面積・周長を属性にリンクし集計表まで作る有料アプリ
- Field Arithmetic（英語圏・63）— フィールド同士を足し引きする計算式を自動作成
- Create a Field-Referenced Copy（英語圏・62）— 元の文字をフィールドで参照する「連動コピー」を作る
- FieldLink（英語圏・62）— フィールドとその参照元を線で結んで見える化
- Lisp các phép tính đại số tự động cập nhật（ベトナム・東南アジア・65）— 数字の文字で組んだ計算式を自動再計算
- MDSTools: Excelセル連携（ロシア語圏・61）— 図面の文字をExcelのセルに紐付けて値を取り込む
- Rutina Lisp para etiquetado completo de parcelas（その他の地域・58）— 区画のラベル付けと技術データ表を一括作成
- Associative Textbox（英語圏・61）— 文字を直すと囲み枠も追いかけて大きさが変わる

## 今のAutoCAD標準機能との違い
- 標準でできる：フィールドで1つの図形の面積・長さを文字に表示する（ただし1個ずつダイアログで設定が必要）。
- 標準でできる：データ書き出し（DATAEXTRACTION）で面積などを表に出す。ただし手順が多く、図面上の表示とは別物になりがち。
- 標準でできない：複数図形の「合計面積」を1つのフィールドで自動作成すること。
- 標準でできない：図形を編集した瞬間に属性や普通の文字を書き換えること（フィールドは再作図や保存のタイミングでしか更新されない）。
- 標準でできない：どの文字がどの図形につながっているかを一目で確認すること。

## 独自アプローチのヒント
- 日本の建築実務向けに「壁芯面積」と「内法面積」を同じ部屋で両方出し、差も表示する面積表を作る。
- 確認申請や重要事項説明で使う「㎡表記・小数点以下2桁切り捨て」など、日本式の丸めルールをフィールドの書式として選べるようにする。
- 面積の文字にマウスを当てると、元の図形をハイライト表示する「逆引き」機能（つながりが切れた文字を見つけやすくする）。
- 図面を開いたときに「フィールドの参照元が消えている文字」（####表示になるもの）を一覧にしてチェックする機能。
- 坪数を自動併記（㎡ ÷ 3.30578）し、不動産向け図面の手間を省く。
- 面積表を作るときに部屋名ブロックの名前も一緒に拾い、「室名・面積・用途」をまとめた表にする。

## 自作の難しさ
★★（中級）— 1つの図形の面積フィールドを入れるだけなら簡単ですが、合計式の組み立てや、リアクタで常に見張る仕組みは不具合が起きやすく、中級以上の工夫が要ります。

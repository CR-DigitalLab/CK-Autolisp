# GitHub上の無料AutoLISP

調査日: 2026-09-26。各リポジトリのライセンスファイル本文を確認しています。★はスター数（概数）。🏢は建築・設備・図面管理関連。

- 「awesome-autolisp」のようなまとめリストは GitHub 上に見つかりませんでした。代わりに GitHub の話題別ページ https://github.com/topics/autolisp が入口として便利です。
- **注意:** 話題別ページには、AutoCADの海賊版・不正キー生成ツールを装った危険なリポジトリが混じっています（例: 「AutoCAD-Keygen」「AutoCAD-2026-Free」「BricsCAD-2026」などの名前）。絶対にダウンロードしないでください。

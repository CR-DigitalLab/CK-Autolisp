# 各サイトの利用規約・再配布可否（直接確認済み）

確認日: 2026-09-26。各サイトの規約ページやファイル本体を直接読んで確認しました。**01〜03の一覧表の「再配布」欄より、こちらの結果を優先してください。**

判定の意味:
- **OK** … 再配布してよいと明記されている
- **条件付きOK** … 条件（無償・無改変・著作権表示を残す等）を守れば配布可
- **不可** … 転載・再配布の禁止が明記されている
- **明記なし** … 許可も禁止も書かれていない（＝勝手に再配布しないのが安全。個人で使うのは可）
- **未確認** … サイトが閉鎖・アクセス制限などで確認できなかった

「無料でダウンロード・使用できる」と書かれていても、**再配布の許可とは別**です。

## 収録しなかった主な理由

- 許可文はあるが「AutoCADの正規ユーザーにだけ配布可」「他のソフトと一緒に配布不可」など、公開リポジトリでは守れない条件のもの
- 本体に「ソースの配布禁止」と書かれていて、説明書の許可と食い違うもの
- 試用期限つきのシェアウェア
- 暗号化されていて中身を確認できないもの
